# ✨ Features

*One proposal per feature in `features/<slug>.md`, listed while it is `proposed`
or `accepted`, in one list sorted by slug. Ship archives a feature with the plan
that implements it, and removes it from this list. Stages and body sections are
defined under Features in `SCHEMA.md` and enforced by
`.iwe/schemas/feature.yaml`.*
