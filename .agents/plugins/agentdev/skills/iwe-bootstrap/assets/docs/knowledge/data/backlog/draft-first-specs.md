# Draft the first specs

Write the first `data/spec/` documents for the behaviour the code already has,
starting with the two or three behaviours everything else depends on. Record the
design decisions baked into that code, with the alternatives they rejected,
under each spec's `## Rationale`. The setup skill proposes the first specs from
the repository; expand them where the drafted version says "unknown". Future
plans cite these specs instead of re-deriving the design from source every
session.
