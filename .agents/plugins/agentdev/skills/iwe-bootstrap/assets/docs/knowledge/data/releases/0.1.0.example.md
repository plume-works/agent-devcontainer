# 0.1.0

*Example document — this shows a release page: frontmatter carries
version/date/stage, and the body says in plain text what changed since the
previous cut. The setup skill deletes `*.example.md` files after onboarding.*

The first usable Pomodux.

## Timer

- A focus session counts down from its configured length and records its
  completion even when the window is closed or minimized.
- A paused session resumes from the time it paused at.
- Elapsed time comes from a monotonic clock, so sleep or a clock change never
  corrupts a session.

## Decisions

- The timer counts wall-clock time
