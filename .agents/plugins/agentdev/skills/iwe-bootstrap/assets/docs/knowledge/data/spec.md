# 📐 Spec

*Behavioral specifications, one topic per document in `spec/<slug>.md`, with
`type: spec`. This folder gets no new text: code and tests state behaviour, a
plan states the behaviour it changes as `## Acceptance` scenarios, and an ADR
records a decision.*
